# Chau7 Advent Calendar

Welcome to the **Advent Calendar** web app, created specially for the **Chau7** student pre-list at ENSEEIHT! 

This project was built to bring festive cheer and excitement to our campus life before the winter holidays. Every day, students can unlock a new event or challenge, earn points using secret codes, and rise to the top of our real-time leaderboard! 

---

## 🌟 The Concept
As part of our campaign for the student union association at ENSEEIHT, **Chau7** created this 19-day interactive calendar:
- **Daily Surprises:** A new window unlocks each day of December to reveal daily events (social gatherings, hot chocolate distributions, challenges...).
- **Points Hunt:** Secret codes are hidden or shared during events. Students scan **QR codes** or enter them manually to claim points and climb the rankings!
- **Holiday Spirit:** A cozy and warm Christmas-themed interface with falling snow animations, garlands, and smooth mobile usability.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Tailwind CSS), and Vanilla JavaScript.
- **Backend & DB:** **Supabase** (PostgreSQL) for user authentication and data management.
- **Security:** PostgreSQL Row Level Security (RLS) and stored RPC functions to process points securely.
- **Deployment:** Vercel / GitHub Pages.
