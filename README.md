# Calendrier de l'Avent Chau7

Bienvenue sur le projet du **Calendrier de l'Avent** conçu spécialement pour la pré-liste étudiante **Chau7** de l'ENSEEIHT ! 

Ce projet a été imaginé et développé pour animer la vie étudiante de notre école avant les fêtes de fin d'année. L'objectif est simple : proposer chaque jour une surprise, un événement ou un défi à nos étudiants, tout en s'amusant à travers un système interactif de points et de classement ! 

---

## 🌟 Le Concept
Dans le cadre de notre campagne pour l'association étudiante de l'ENSEEIHT, la pré-liste **Chau7** a mis en place ce calendrier interactif sur 19 jours :
- **Découverte quotidienne :** Chaque jour de décembre, une nouvelle case se débloque pour révéler l'événement du jour (soirées, distributions de chocolats chauds, défis...).
- **Chasse aux points :** Des codes secrets sont cachés ou distribués lors de nos événements. Les étudiants peuvent les flasher via des **QR codes** ou les saisir manuellement pour grimper dans le classement !
- **Esprit de Noël :** Une interface chaleureuse avec de la neige qui tombe, des décorations festives et une navigation super fluide sur mobile.

---

## 🛠️ Stack Technique & Architecture
- **Frontend :** HTML5, CSS3 (Tailwind CSS) et JavaScript Vanilla.
- **Backend & Données :** **Supabase** (PostgreSQL) pour la base de données et la gestion sécurisée des utilisateurs.
- **Sécurité :** Row Level Security (RLS) et fonctions SQL RPC pour sécuriser l'attribution des points et éviter les doublons.
- **Déploiement :** Vercel / GitHub Pages.
